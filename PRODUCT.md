# BokBac Product Context

## Register

Product.

## Product Purpose

BokBac is an educational bacterial identification workspace for medical technology students, microbiology educators, and software reviewers. It helps users move from specimen context and Gram stain observations through biochemical tests toward ranked bacterial identification results.

## Users

- Medical technology students learning isolate workup logic.
- Microbiology educators demonstrating diagnostic reasoning.
- Reviewers checking Bayesian scoring, test-suite behavior, saved cases, and reference data.

## Brand And Tone

BokBac should feel like a premium clinical microbiology workstation: dark, focused, precise, Thai-first where the legacy interface established Thai labels, and dense enough for repeated lab use. The old v3 visual language is the visual reference: midnight background, Liquid Glass surfaces, violet/gold/cyan accent line, compact pill navigation, scientific emoji marks, and glowing primary actions.

## Strategic Principles

- The maintained application is v4 in `v2/`.
- Legacy v3 is reference-only, but its visual language is the target aesthetic.
- New v4 features should look native to the legacy visual system instead of looking like separate Tailwind defaults.
- Educational safety remains explicit; the app is not a clinical diagnostic system.

## Anti-References

- Generic SaaS dashboard styling.
- White clinical admin UI.
- Marketing landing-page heroes.
- Bland card grids without diagnostic density.
- UI that hides the workflow behind decorative effects.
